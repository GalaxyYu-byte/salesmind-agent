# SalesMind 前端

Vue 3 + TypeScript + Vite + Plotly.js。经营工作台、数据页和模型意图分析对话已连接真实 MySQL 查询接口。

## 联调启动

项目根目录的 `.env` 使用服务器直连地址（MySQL 3307、Redis 6380），无需 SSH 隧道。可双击 `start-dev.bat` 一键启动，也可在项目根目录的独立终端启动 API：

```powershell
.venv\Scripts\python.exe -m uvicorn salesmind.main:app --host 127.0.0.1 --port 8000
```

前端终端：

```powershell
cd frontend
npm ci
npm run dev
```

访问 http://127.0.0.1:5173 。Vite 开发代理将 `/api` 和 `/health` 转发至本机 8000，可用 `SALESMIND_DEV_BACKEND_URL` 修改目标。`npm run build` 输出静态资源；生产部署需要另行配置反向代理，Vite preview 不包含开发代理。

## 已接通的接口

`GET /api/v1/sales/overview?start_month=2026-03&end_month=2026-08&region_id=2`

- 月份参数必须同时提供或同时省略；省略时按数据库完整水位选择最近六个月。
- 支持 1–24 个连续完整月；区域省略表示全部可见范围。
- 仅统计 COMPLETED 订单，以订单所属区域为准，排除取消与退款订单。
- 返回 MySQL 来源、查询时间、数据版本、水位、维度、当前期与去年同期聚合，以及精确金额总额。
- 金额总额为十进制元字符串，聚合单元为整数分字符串；前端校验金额、订单数和请求范围一致性。
- 错误返回 422（范围无效）、404（区域不存在）、503（连接不可用）或 504（查询超时）。失败时显示错误，不回退到固定演示结果。

销售接口必须登录后携带 Access Token。首次打开页面显示用户名、密码和图片验证码登录页；销售员查看本人订单，经理查看授权区域，总监查看企业订单；各角色均受指标白名单限制。Access Token 有效 30 分钟，Refresh Token 有效 7 天并由 Redis 管理。配置、Cookie 与部署说明见 [登录模块](../AUTH.md)。

联调实测 2026-03 至 2026-08：销售额 4,782,185.61 元、毛利 1,673,824.69 元、已完成订单 1,750 笔。当前 MySQL 保存的是项目生成的样例订单；真实查询不代表生产业务数据。

## 可用功能与边界

工作台和数据页切换时间或区域会重新请求接口，趋势、排名、同比与导出基于查询结果。接口不读取用户提供的原始 SQL，不写入业务数据。

分析对话提交原始问题，由后端 DeepSeek 提取指标、时间、区域和分析方式并校验，再通过鉴权 fetch 订阅 SSE。缺少条件进入澄清，用户提交原始补充回答；支持连续补充，以及同一会话内“华南呢”等追问保留上一轮时间、指标；页面显示已确认条件和继承项。支持汇总、月趋势、商品排名和区域对比，模型配置见 [基础意图解析](../INTENT.md)。LangGraph 已组织查询、计算、排序、生成图形数据和保存结果；页面按实际计划展示执行步骤，区域同比结果包含可核对的明细表。服务端会话、任务、事件与快照已存 MySQL，登录设备会话存 Redis。任务接口、状态和单实例要求见 [会话与 SSE](../CONVERSATIONS.md)。

暂停或取消向后端发送控制请求，阻止晚到结果覆盖状态；关闭页面只断开订阅，不取消任务。前端按序号重连并去重事件，连接失败达到重试上限时可重新打开会话同步状态。继续时保留原任务和分析范围：后端若已保存有效查询检查点，就读取原查询快照，从计算阶段继续，不再查询；查询尚未完成时仍会重查。当前只保存查询检查点，计算、排序或画图中断后会从计算阶段重做。检查点过期、损坏或权限/版本变化时，继续返回 409 或 410，任务仍可取消并重新创建。

分析会话从服务端分页读取，历史结果通过 artifact 接口加载并校验范围与金额。快照包含 MySQL 数据版本和查询时间，过期或权限变化时明确提示重新分析。报告在 localStorage 中仅保存服务端结果 ID 和不含数值的分析条件，打开与导出重新鉴权；旧完整快照不导入。Token 不写入 localStorage。`src/data/fixture.json` 仍用于旧记录、历史期间选项和离线单元测试；本地规则解析器仅保留为旧演示测试；接口失败时不作为业务结果回退。

分析模板支持环比、指定商品对比和月度异常检测。环比趋势按每月与上月比较，汇总与维度对比使用上一等长期间；页面按服务端返回的基期名称展示。异常检测显示历史窗口均值、偏离率与异常标记，默认使用前 3 个完整月和 30% 阈值；窗口或基期不足显示不可检测。报告索引保留商品选择、环比排序和异常参数，CSV 与 Markdown 导出包含相应比较或检测明细。

自动查询可复用服务端权限范围内的短期缓存，并保留原查询时间；“刷新数据”和失败重试主动跳过缓存。浏览器请求保持 `no-store`，不保存销售查询快照。

Plotly 图表懒加载，加载失败保留数值表格。异常检测保留期望曲线与独立异常点标记。金额以整数分计算，仅显示时转换为元。

## 验证

```powershell
npm test
npm run build
```

前端还验证登录恢复、Token 自动刷新、并发合并、退出失败处理和本地账号隔离。前端测试覆盖金额精度、同比覆盖、日期解析、区域追问、真实接口映射、取消信号、请求范围、失败不回退及不一致金额拒绝。后端 `tests/test_sales_overview.py` 验证真实 SQL 聚合、订单状态、时间边界、空区域、范围约束、登录保护和超时。
